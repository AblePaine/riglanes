Standard test protocol (v0.1)

  1. Print in PETG unless the designer says otherwise; record filament brand, layer height, walls, infill.
  2. Fit check: mounts without force? clears neighbor slot? record pass/fail + notes/photo.
  3. Room ambient measured at the intake, 20–26°C; record it.
  4. Fixed power limit (same watts for every part on the same GPU model); fixed fan duty if controllable, else record.
  5. Load for 30 min with the same load command (scripts/rigbench_test.py), samples every 5 s.
  6. Report max temp, last-5-min average, ΔT over ambient, fan %, noise dBA at 1 m (phone meter, labeled approximate).
  7. Compare only within the same GPU model and power limit.

Uploader claims are copied from the model page and are not verified. Some pages blocked our fetcher; those claims are marked as coming from a search summary.
